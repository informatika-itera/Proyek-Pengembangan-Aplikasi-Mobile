# Screenshots

Folder ini berisi screenshot aplikasi InventRa untuk dokumentasi README.

## Cara mengambil screenshot:
1. Jalankan app di emulator/device
2. Navigasi ke masing-masing screen
3. Tekan Ctrl+S (emulator) atau tombol screenshot di device
4. Simpan dengan nama yang sesuai:
   - splash.png
   - login.png
   - dashboard.png
   - catalog.png
   - detail.png
   - history.png
   - ai.png
   - profile.png
   - dark.png
